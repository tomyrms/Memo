# Publication du projet et des issues

## Destination

Dépôt fourni par le propriétaire : [tomyrms/Memo](https://github.com/tomyrms/Memo). Le dépôt a été créé par son propriétaire et est public. La documentation et le backlog contiennent des contraintes techniques et des résultats agrégés ; les fichiers personnels utilisés pour le cadrage ne sont pas destinés au dépôt.

## Backlog

`issues.json` est la source structurée : chaque entrée possède un identifiant stable `SD-xxx`, un titre, une phase M1/M2/M3, une priorité, ses dépendances et un corps Markdown avec critères d'acceptation.

Les identifiants `SD-xxx` ne sont pas des numéros GitHub. Les 20 issues ont été créées le 30 octobre 2026. `github-issues.json` conserve la correspondance vers les numéros et URL effectivement renvoyés. En cas d'interruption, relire les issues existantes avant de reprendre pour éviter les doublons.

Les phases de développement sont documentées dans la feuille de route et dans chaque issue. Leur présence dans ces documents ne signifie pas qu'un objet GitHub Milestone ou GitHub Projects a été créé.

Les issues ont été publiées dans l'ordre des identifiants avec leurs liens de dépendance vers les numéros réels. Conserver les modifications des utilisateurs lors d'une reprise ultérieure.

## État du logiciel

Ce dépôt initialise le projet et ses tâches. Les critères cochables décrivent du travail à réaliser ; aucune fonctionnalité de l'application n'est encore déclarée implémentée.
